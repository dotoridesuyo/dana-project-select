# 김단아 · 포트폴리오

게임의 프로젝트 선택 화면을 응용한 포트폴리오입니다.

홈페이지: https://dotoridesuyo.github.io/dana-project-select/

프로젝트 여섯 개의 소개와 포트폴리오 이미지, 기획 문서·플레이·대화·음악 링크를 제공합니다. index.html에서 사이트를, editor.html에서 화면 편집기를 열 수 있습니다. 별도 빌드가 필요 없는 HTML/CSS/JavaScript 사이트이며 경로는 상대 경로를 사용합니다.

화면 편집 설정은 현재 브라우저에 저장됩니다. 다른 주소나 브라우저로 옮길 때는 편집기의 설정 내보내기·불러오기를 이용할 수 있습니다.

## 게시 파일

사이트 화면 파일은 저장소 루트에, 이미지 28개는 `assets.zip`에 들어 있습니다. GitHub Actions가 이미지를 풀어 정적 파일만 GitHub Pages로 게시합니다. `.github/workflows/pages.yml`은 main 변경 시 실행됩니다. 인증 키나 별도 계정 비밀 값은 필요하지 않습니다.
